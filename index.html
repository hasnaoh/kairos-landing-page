Luxury resale pricing is harder than it looks. A Chanel bag from a particular creative director era, in a specific condition, with original accessories, at a moment when search interest is declining — that's a four-variable problem that static comp-based tools handle poorly.

When an item is overpriced, it sits. Markdown follows markdown. Buyers learn to wait. The cascade depresses perceived value across the category. Platforms absorb the loss.

Current tooling — manual comp pulls, basic regression against recent sales — misses two critical signals: archive premium (collector demand for specific eras and creative directors) and trend timing (whether interest is currently rising, flat, or declining). Kairos targets exactly these gaps.

Architecture

Five-stage pricing pipeline

01

Item Input

Structured form fields plus free-text item description. Accepts condition notes, era, accessories, and any detail the consignor provides.

React FastAPI
02

AI Parsing Layer

Claude Haiku extracts structured features from the free-text description: era, creative director period, condition notes, accessories flag, collab indicators, and aesthetic tags.

Claude Haiku Anthropic API
03

Feature Engineering

Parsed attributes become model-ready features: brand_tier, condition_score, msrp_ratio, saturation_index, archive_score, accessories_flag. The archive score encodes collector premium for specific creative director periods.

Python
04

XGBoost Regression + Quantile Confidence

Gradient-boosted model trained on historical resale transactions. Quantile regression surfaces a confidence range alongside the point estimate. Target: ≥15% MAPE improvement over median-sales baseline.

XGBoost scikit-learn
05

Trend Adjustment Layer

Google Trends RSV data (2-week lag) surfaces a timing signal — rising, flat, or declining — for the brand and category. The output price and rationale reflect this signal so merchandisers know not just what to charge, but when.

Key Insight

Timing is not a footnote. It's a pricing input.

Why comp-based pricing is incomplete

Most resale pricing tools look at what similar items sold for. That tells you historical clearing price. It does not tell you whether this is the right week to list at full price or whether the category is in a cooling phase where markdown is almost guaranteed.

Kairos adds a two-week-lag RSV (Relative Search Volume) signal from Google Trends. If interest in Balenciaga Triple S has been declining for three weeks, that is a pricing input. A merchandiser should know it before the item goes live, not after the first markdown.

Rising
Hold or stretch price. Demand is building. Early markdown is value destruction.
Flat
Price to model. Comp-based estimate is likely accurate. Standard listing strategy.
Declining
Consider immediate discount or delay listing. Market cooling reduces clearing price.
